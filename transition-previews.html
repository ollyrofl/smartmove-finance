Transition Preview

Four teal motion directions to compare.

Each card below uses the same Smartmove-style image panel and a different page-load feeling. Hit replay on any option to see the motion again. Once you pick one, I can apply it site-wide.

Option A

Soft Fade

A calm fade with a light teal wash and just a little blur.

Soft Fade

Clean

The safest option. It feels polished and quiet, with a bit of softness as the page resolves into focus.

Option B

Teal Wipe

A branded wipe that clears away into the page instead of a standard fade.

Teal Wipe

Brand-led

More intentional and obviously custom. It uses teal as a curtain that slides away, so the page feels distinctly branded.

Option C

Focus Pull

The page starts slightly soft and zoomed, then sharpens into place.

Focus Pull

Cinematic

This one feels more editorial. It gives the sense that the page is coming into focus rather than just appearing.

Option D

Teal Glow

A short glow bloom that flashes through teal before settling.

Teal Glow

Lively

The most energetic option here. It still stays tasteful, but it has more personality than a standard fade.
